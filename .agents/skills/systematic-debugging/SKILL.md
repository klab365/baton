# Systematic Debugging

- Inspect the reported problem, relevant context, changes and error output.
- Reproduce the issue when practical; otherwise state what prevents reproduction.
- Trace the evidence to a likely root cause. Test hypotheses with focused, safe diagnostics.
- Report observations separately from assumptions, including commands and results.
- Suggest actionable next steps and identify any unresolved prerequisites. Do not claim an unrun check passed.
